## R-44 — type tokens that were never defined resolve to the type floor or the `-ui` step, never a new token

Found fixing R-40 fallout: `--t-micro` (ReturnWorkspace) had no definition; `--t-body-sm`
(ResolveCaseModal) had no definition. The scale in `theme.css` is explicit that **--t-th is
the floor — nothing renders below it**. So: the below-floor ask becomes `--t-th`; the
"slightly smaller than body" ask becomes `--t-ui`. No new type token is minted to satisfy a
name — the name goes to the existing step.
Revert: re-add the alias token in `theme.css` and re-point.
