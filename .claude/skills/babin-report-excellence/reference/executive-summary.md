# Executive Summary & Insight Generation

The summary is the only section guaranteed to be read. It must stand alone: an owner who reads only this should know the answer and the next move.

## Structure (answer-first — Pyramid Principle)
Lead with the answer, then group ~3 MECE reasons, then evidence sits below in the body.
Set it up with **SCQA** compressed to a few lines:
- **Situation** — the stable context ("Q3 rentals ran across 62 bookings").
- **Complication** — what changed / the tension ("but lighting utilization dropped 14%").
- **Question** — the implicit question ("where is idle capital sitting?").
- **Answer** — the recommendation, stated plainly and first in the rendered order.

Rendered order in the report:
1. **Overall status line** — a status pill + one sentence. ("On track — revenue up 12%, one risk to watch.")
2. **The recommendation** — one sentence, the single most important action.
3. **Top 3–5 findings** — tight list, each a finding not a topic.
4. **Business impact** — framed in money/time/risk/efficiency.
5. **Read-time** — "3 min read."

## Action titles (not topic titles)
Every heading and finding states the insight:
- Topic: "Lighting utilization." → Finding: "Lighting gear sat idle 40% of the quarter."
- Topic: "Overdue payments." → Finding: "NPR 180k is >30 days overdue across 4 clients."

## Insight phrasing (fold the old "insight generator" here)
A finding is an insight when it is non-obvious and actionable. Test each with: **so what → now what.**
- Weak: "Revenue increased 12%."
- Insight: "Revenue rose 12%, but 70% came from 3 clients — concentration risk if one leaves."
Attach a **business-impact tag** (High/Medium/Low) to each insight so the owner can triage.

## Business-impact framing
Translate every finding into one of: revenue gained/lost, cost saved/spent, time saved, or risk raised/reduced — with a number wherever the data allows. "High impact" with no number is a guess; back it.

## Length
1–2 pages / one screen. If it doesn't fit, the findings aren't tight enough — cut, don't shrink the font.
